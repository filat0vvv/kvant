# Kvant

Клиент Telegram для обычного аккаунта, с теми же чатами и контактами. База: публичные исходники exteraGram, зафиксированные на коммите `6f78031aafd7f27e0dfaa31a207715569a6df1a2` (версия Telegram 9.6.6). Это старая база: перед публичным распространением нужен переход на актуальную поддерживаемую версию.

## Сборка

1. Получить собственные `api_id` и `api_hash` на <https://my.telegram.org/apps>.
2. В Settings → Secrets and variables → Actions добавить repository secrets `TELEGRAM_API_ID` и `TELEGRAM_API_HASH`. Значения вводить без кавычек. Не публиковать их в коде, issues или чате.
3. В Actions запустить «Сборка Kvant APK». Параметр `app_id` задаёт Android package name, например `com.kvant.messenger`; он отличается от числового Telegram API ID.
4. После успешной сборки скачать артефакт `Kvant-Android-APK`.

Сейчас сценарий создаёт новый ключ подписи при каждой сборке. Такие APK предназначены для разработки: без одного постоянного ключа нельзя устанавливать последующие сборки поверх предыдущих. До распространения приложения настройте постоянную подпись и сохраните резервную копию ключа.

## Подключение без отдельного VPN

При отсутствии подключения в открытом приложении Kvant ждёт восстановления связи около 20–30 секунд, затем загружает списки MTProto-прокси и проверяет кандидатов средствами Telegram. После выбора прокси настройка сохраняется для всех аккаунтов. При следующем обрыве выполняется новый поиск с паузой между попытками. HTTP-запросы выполняются в отдельном потоке; устаревшие результаты проверок не могут заменить уже выбранный сервер.

Работающий прямой канал и вручную заданный прокси сохраняются. Автовыбранный прокси можно отключить в стандартных настройках Telegram: автоматическое включение после этого прекращается. Чтобы возобновить автоматическое восстановление, включите тот же автоматически выбранный прокси.

Списки берутся из сторонних публичных источников, перечисленных в `.github/templates/AutoProxyManager.java`. Эти источники и сами прокси могут стать недоступны. Для контролируемого сервиса нужны собственные либо доверенные прокси и доступные пользователям источники их адресов. Работа во всех сетях не гарантируется. MTProto-прокси не обеспечивают обход блокировки голосовых и видеозвонков; звонки требуют отдельного решения.

## Изменения базы

Публичная база ссылается на отсутствующие классы пакета `com.exteragram.messenger.boost`. Сценарий удаляет дополнительные меню шифрования/расшифрования Boost и вызовы его фильтра Zalgo. Заглушек шифрования нет. Код стандартных секретных чатов Telegram сохраняется.

Настройка `APP_PACKAGE` меняется в `gradle.properties`; поля BuildConfig не обнуляются массово. Плагины Google Services и Crashlytics отключены вместе; это не означает удаления зависимостей Google/Firebase или полной поддержки push-уведомлений без их настройки.

Проверки патча останавливают сборку, если ожидаемые участки исходников изменились. Configuration cache отключён, а `--stacktrace` включён для диагностики ошибок Gradle.

## Проверка перед выпуском

Локальная проверка патча и синтаксиса не заменяет успешную Android-сборку и испытание APK. Проверьте вход в аккаунт, получение и отправку сообщений, вложения, секретные чаты, отключение выбранного прокси, ручной выбор и восстановление после потери связи в нужных сетях.

Источники: [исходники exteraGram](https://github.com/exteraSquad/exteraGram), [Telegram API ID](https://core.telegram.org/api/obtaining_api_id), [Telegram MTProxy](https://core.telegram.org/proxy). Исходники Telegram/exteraGram и изменения к ним распространяются с соблюдением их лицензий; см. LICENSE в базе.
