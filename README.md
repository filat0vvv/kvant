# kvantGram для Android

Кастомный клиент **на базе AyuGram4A и exteraGram**, с собственным именем и логотипом kvantGram.

## Что отличается от прежнего APK

- Режим призрака: переключатель в боковом меню, управление статусом online, набором текста и отметками чтения.
- Локальная история изменений и удалённых сообщений; просмотр прежних версий из меню сообщения.
- Сохранение доступных вложений в отдельную приватную папку приложения, независимо от обычного кэша Telegram.
- Настройки exteraGram: Solar-иконки, новые переключатели, оформление вкладок, темы Monet и параметры интерфейса.
- Отдельные разделы «kvantGram · Призрак и история» и «kvantGram · Оформление».
- Свои Telegram API credentials и постоянная подпись; стороннее автообновление отключено.

Режим призрака включается пользователем. История правок и удалений включена по умолчанию.
Скрытие прочтения после отправки ответа больше не выключается настройкой по умолчанию.
Сохраняются только сообщения и файлы, доступные клиенту: пропущенные до установки удаления восстановить нельзя.
AyuSync оставлен выключенным по умолчанию; локальная история не требует стороннего сервера.

## Отдельная установка и версия базы

Пакет: **`com.kvant.messenger.ayu`**. Имя под иконкой: **kvantGram**. Архитектура: **arm64-v8a**.
Этот APK устанавливается рядом с прежним kvantGram. Не удаляйте прежнюю установку ради новой.

Открытый AyuGram основан на Telegram **9.6.6**, что старше прежней базы Telegram-FOSS 10.14.3.
Поэтому новый APK не открывает старую локальную базу и не копирует её поверх своей.
В новом приложении нужен отдельный вход. Серверные чаты синхронизируются через Telegram;
локальные секретные чаты и иные данные старого приложения автоматически не переносятся.
Скрипт запрещает использовать прежний пакет `com.kvant.messenger`, чтобы не допустить понижения схемы.

Зафиксированные исходники: [AyuGram/AyuGram4A, 7013145676d36d82ee13c02a89f72097b7490dcd](https://github.com/AyuGram/AyuGram4A/commit/7013145676d36d82ee13c02a89f72097b7490dcd).
Это публичная ветка 2023 года; APK не объявляется эквивалентом современной закрытой сборки AyuGram.

## Недостающая открытая история

README AyuGram требует самостоятельно реализовать AyuMessageUtils и AyuHistoryHook.
Закрытый подмодуль не скачивается. Вместо него здесь открытые классы в `android/com/kvant/messenger/history`:

- Снимки Telegram TL с текстом, форматированием, ответами, медиа и реакциями.
- Восстановление локальных удалений в страницах чата с фильтрацией по аккаунту, диалогу и теме, без удаления живых сообщений.
- Копирование доступных файлов в `files/kvant-history/<user>/<dialog>/<message>`.
- Добавочная миграция Room 21 → 22; destructive migration удалена.
- Проверяемая политика исходящих read/typing/online пакетов на существующей границе запросов AyuGram.

Недоступные необязательные Boost-расширения удаляются; заглушки шифрования не используются в чате.
Код стандартных секретных чатов Telegram не заменяется. Google Maps API не настроен; соответствующие карты могут быть недоступны.

## Сборка

В репозитории уже настроены шесть Actions Secrets:
`TELEGRAM_API_ID`, `TELEGRAM_API_HASH`, `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`,
`ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`. Не помещайте значения в исходники или PR.

[Actions](https://github.com/filat0vvv/kvant/actions) → **kvantGram — APK и проверки истории** → Run workflow
на ветке `codex/kvantgram-ayugram`. Оставьте отдельный пакет по умолчанию.

Сценарий применяет `scripts/brand_ayu.py`, запускает регрессионные тесты и собирает подписанный APK.
Артефакты: `kvantGram-Android15-APK` и `kvantGram-Ayu-test-results`.

## Проверка

Локально проверены применение патча к указанному коммиту, XML, отсутствие ссылок на закрытый подмодуль,
сохранение разделов настройки и встраивание истории. Предыдущая сборка прошла 9 JVM/Room-тестов.
Исправление запуска убирает обращение к ненастроенному Firebase; заставка Android 12+ и все варианты
иконок получают собственные ресурсы kvantGram. Обновление сохраняет прежний пакет и подпись,
повышая код сборки. После сборки запускается проверка подписанного APK на эмуляторе Android 15:
три холодных запуска и переход к вводу номера без авторизации. Используется присланный пользователем знак из двух серебристых орбит.
На холодном старте орбиты соединяются на общем синем фоне и переходят в прозрачный знак.
Тап пропускает анимацию; отключённые системные анимации учитываются.
Дополнительная стартовая Activity не создаётся, маршруты ссылок и уведомлений не меняются.
Авторизация и реальное поведение призрака, истории, медиа и звонков требуют проверки на телефоне.
