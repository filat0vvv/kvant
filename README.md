# kvantGram для Android

Кастомный клиент на базе Telegram **13.1.1**, с режимом призрака, локальной историей правок и удалений, собственным знаком и анимацией соединяющихся орбит.

## Возможности

- Фото и видео на один просмотр, голосовые и видеосообщения на одно прослушивание/просмотр.
- «Призрак · kvantGram» в главных настройках клиента и переключатель в боковом меню.
- «История и инструменты kvantGram»: сохранение доступных клиенту удалённых сообщений, прежних версий и вложений. История включена по умолчанию, призрак включается пользователем.
- Собственный канал [@kvantgram_official](https://t.me/kvantgram_official) и [исходный код](https://github.com/filat0vvv/kvant) в разделе «О приложении». Ссылок на сторонний чат и поддержку нет.
- KvantSync — локальный экспорт и восстановление настроек. Собственный облачный сервер синхронизации пока не настроен.
- Собственный логотип под иконкой, на заставке, при первом запуске и в разделе «О приложении». Анимация учитывает системное отключение анимаций и пропускается касанием.

## Обновление

Пакет **`com.kvant.messenger.ayu`**, имя **kvantGram**, архитектура **arm64-v8a**, код версии **40000**. APK подписывается прежним постоянным ключом и устанавливается поверх Ayu-версии kvantGram (сборка 33649). Удалять установленное приложение не нужно.

История `ayu-data` сохраняет внутреннее имя для совместимости. Добавочная миграция Room 21/22 → 27 поддерживает как исходную схему, так и прежнюю схему kvantGram с полными TL-снимками. Сохраняются аккаунты, текст, форматирование, ответы и пути к приватным вложениям. Автоматическое удаление базы при понижении версии отключено.

Пакет раннего Telegram-FOSS-форка `com.kvant.messenger` другой: его локальные секретные чаты и другие приватные данные автоматически не копируются.

## Закреплённая основа

[NagramXTurbo, коммит 0a4372f9b4927b014a21eaa9fc8af4b4efb6af12](https://github.com/temporaryna/NagramXTurbo/commit/0a4372f9b4927b014a21eaa9fc8af4b4efb6af12), Telegram 13.1.1. Свежая публичная база включает открытые реализации режима призрака и истории. Старый рецепт AyuGram 9.6.6 сохранён для воспроизводимости прежних сборок.

## Сборка

[Actions](https://github.com/filat0vvv/kvant/actions) → **kvantGram 13.1.1 — APK и проверка обновления** → Run workflow на ветке `codex/kvantgram-ayugram`.

Нужны шесть Actions Secrets: `TELEGRAM_API_ID`, `TELEGRAM_API_HASH`, `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`. Значения не помещаются в исходники, PR или архивы.

Рецепт `scripts/brand_modern.py` применяет брендинг, ссылки, перенос настроек и истории. `scripts/reuse_native_modern.py` извлекает только `libtmessages.49.so` из [успешной сборки точного коммита основы](https://github.com/temporaryna/NagramXTurbo/actions/runs/40912825852), проверяя SHA-256 APK и неизменность native-исходников. Старая библиотека Telegram 9.6.6 не используется.

Артефакт `kvantGram-13.1.1-Android-APK` содержит подписанный APK, контрольную сумму, архив рецепта, патч исходников и сведения о происхождении native-библиотеки. Отдельные артефакты содержат результаты тестов и проверки запуска.

Сторонние обновления и ненастроенный Firebase отключены. Официальные passkeys требуют инфраструктуры издателя и отключены; обычный вход по номеру остаётся. Google Maps API издателя пока не настроен.

## Проверка

Все 7 JVM/Room-тестов прошли. Подписанный APK прошёл три холодных запуска и переход к вводу номера на Android 15 без вылетов. Приветственный экран и анимация просмотрены. [Сборка и проверки](https://github.com/filat0vvv/kvant/actions/runs/41075622103). Код приложения: `9f153c620679920e8b8e87396770f43bb123f6d5`. Вход в реальный аккаунт, доставка одноразовых сообщений, звонки и поведение истории на пользовательском телефоне требуют отдельной проверки.
